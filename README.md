# DigiPay Black Friday Landing Page

Static RTL landing page for GitHub Pages.

## Upload to GitHub
Upload the **contents** of this folder to the repository root so that `index.html` is visible at the top level.

Required structure:

- index.html
- styles.css
- script.js
- fonts/
  - YekanBakhFaNum-Thin.woff2
  - YekanBakhFaNum-Light.woff2
  - YekanBakhFaNum-Regular.woff2
  - YekanBakhFaNum-SemiBold.woff2
  - YekanBakhFaNum-Bold.woff2
  - YekanBakhFaNum-ExtraBold.woff2
  - YekanBakhFaNum-Black.woff2
  - YekanBakhFaNum-ExtraBlack.woff2

No CDN or external font dependency is used.
