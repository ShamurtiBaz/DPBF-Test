# DigiPay Black Friday Landing Page

A lightweight static RTL landing page for GitHub Pages.

## Publish on GitHub Pages
1. Create a new public repository, e.g. `digipay-blackfriday`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. GitHub will provide a public HTTPS URL.

No build step, framework, external font, image library, or CDN is required.
